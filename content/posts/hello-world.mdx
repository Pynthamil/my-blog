# Welcome to Local MDX

We've successfully moved away from the Hashnode GraphQL API. This blog is now powered entirely by **local Markdown files**. 

## Why MDX?

MDX allows you to write markdown but with the power of React components embedded directly inside!

### Features
- **Fast**: No external API calls needed
- **Flexible**: Complete control over your content
- **Free**: No API limits or paywalls
